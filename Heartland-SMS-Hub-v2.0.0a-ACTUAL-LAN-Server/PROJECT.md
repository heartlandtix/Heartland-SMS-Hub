# Heartland SMS Hub

## Current milestone

Phase 2.0.0a: LAN web server.

## Completed

- Read SMS through Windows Mobile Broadband.
- Decode GSM 7-bit and UCS-2 PDUs.
- Combine multipart messages.
- Searchable inbox.
- Continuous five-second monitoring.
- Detect and display new messages.
- Embedded LAN HTTP server on port 8080.

## Next

- Confirm access from a second computer.
- Replace page reloads with a messages API and live updates.
- Add authentication before any Internet exposure.
- Add multiple modem identities and friendly names.
- Add watchdog and recovery diagnostics.
